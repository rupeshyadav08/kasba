# Story Shorts: how to write one

Each `<name>.json` here becomes one Short on the YouTube channel (and the same file as an Instagram Reel).
`story-daily.yml` posts them in `order.txt` order, two a day. Rules:

- **True and sourced.** Only well-documented stories. Name the sources in the description. Say "it's said" for
  anything disputed. Skip tragedies that a cartoon style would cheapen (e.g. atomic bombings).
- **Hook first (`hook` + line 1).** Open on the punchline, never an intro. `hook` is the big text for the first 2 s.
- **A cut every ~2 s.** Two `shots` per line; `{hero}` is replaced by `cast` so the main character stays the same.
- **Loop ending.** The last line leads straight back into line 1 ("...remember that" → "A famous scientist threw a
  party..."), so the replay feels seamless.
- **Share prompt (`share`).** On screen for the last 3 s: "Send this to someone who...". No emoji (the caption font
  has none).
- **Description.** First line = searchable keywords ("True story: ..."), second line = a comment question, then
  the longer summary, sources, the AI note, and 3-5 specific hashtags (always `#shorts #truestory` + 2 topical).
- **Length.** 7 lines, about 100 words ≈ 30-35 s. Emu War (117 words, 38 s) averaged 22 s watched on Instagram (58%); shorter keeps more people to the end.
